# 基于现有材料的标签判断

用户于 2026-11-20 明确要求：Country 可根据已有材料综合推断；没有 Moka Note 时，也要根据 Taxonomy 和简历尝试判断项目 Tier。此为用户确认的工作口径，不证明组织 Admin 已批准或发布了不同于正式文档的制度。先识别用户授权范围；建议不等于已写入或已完成正式评估。

## Country：推断当前所在地

- 目标仍是候选人**目前实际所在地**。优先使用明确且较新的居住地或档案地址；不把国籍、姓名当所在地。
- 若未直接写明，综合简历及申请中有时间、来源的线索，例如电话号码、现职或近期工作地、求学经历、岗位工作国家/地区。多项线索同向、整体足以合理判断时，按用户要求推荐对应国家；不要仅因没有单独现居地确认而留空或追问。
- 记录每项证据、时间和推断性质，不把推断写成已核实的居住事实。历史求学和电话号码可能过时，岗位市场也不等于居住地；不得将某一个线索机械设为必然充分条件。
- 用户明确接受的匿名模式：简历有美国电话号码和过去美国求学经历，同时申请美国岗位，可综合建议 `united states`，并注明是推断而非候选人明确填写的现居地。不以此固定推断所有相似候选人，结合具体事实判断。
- 新近明确的现居地与间接线索不同，优先采用明确现居地；互相矛盾且无法判断，或线索过少不能合理推断时，列待核实。未知不是 `country not included`。
- 如用户要求实际写入，还需核对当前获批政策与库、身份、既有值和权限；如果当前正式政策不允许此推断，暂停该组写入并报告冲突。此核对不等于再次要求候选人确认住址。

## Tier：没有 Note 时主动判断

1. 明确目标项目、具体工作和 Target Profile；不能确定时按已提供职位材料说明暂定范围。阅读简历、资料、相关 Note 或评估，区分个人真实经历和岗位要求。
2. 对照 Taxonomy 的专业知识、相关实践、任务复杂度、独立性、专业判断、对决定与结果的责任六维，摘录有证据的工作、产出和职责；不把岗位职责、年限、学历、头衔或单一指标当作已证明的能力。
3. 对照四档给出最有依据的**项目级初步建议**：`tier 1` 为方法论设计、高风险判断和复杂最终裁决的顶级专业能力；`tier 2` 为复杂任务、困难案例、错误归因和专家质检方面的强专业能力；`tier 3` 为可独立完成领域工作、识别问题及处理常规升级；`tier 4` 为按 SOP、指南和示例完成标准化任务。按整体证据判断，不凭单条条件或年限机械定级，不强行满足每一条措辞或编造分数线。
4. 说明支持该档的个人证据、关键缺口及可能改变判断的事实。没有 Note 或已批准项目细分 rubric 本身不是拒绝给出初步建议的理由；材料对关键维度实质不足、证据冲突或项目上下文无法建立时，诚实列待审核，不硬猜等级。不要用 `tier not included` 表示未评估。
5. 若有与同一项目及 Target Profile 可信关联的 Note，记录作者、日期和原文并纳入判断；区分既有人工结论与自己的初步建议。项目归属不明或不同证据冲突时说明，不把其他项目结论当作当前项目结论。不同项目分别判断，不取跨项目最高值、不自动覆盖历史。
6. 只有在相应适用规则、有效证据、身份和项目上下文经正式核验后，才可称已完成正式评估。初步建议即使有档位名称，也不是正式评估或自动写入授权。Tier 的项目隔离、历史保留、实际权限及适配门控未经核验前，仍阻断写入。

## 其他组与输出

- 六组均按适用性逐项检查。Language 基于候选人明确可支持语言；Project Category 根据个人能做的工作；Knowledge Domain 根据实质知识或技术实践。规范标签须在快照中核对精确拼写，现行批准及 Active 状态另行核验。
- `prompt development` 可由实际编写或设计给 AI 系统的评测任务提示等证据支持，不必额外要求职位名称叫 Prompt Engineer。`llm coding evaluation` 与 `agent task completion evaluation` 可分别依据生成代码评测和任务结果验证支持；多步轨迹、规划和工具操作等其他 Agent 评测项需各有相应个人证据。
- 项目标记根据实际岗位及其关联 requisition 的具体任务语义判断，表示项目关联；不得把职位要求当作候选人已具备该能力的证据，也不假定其与 Taxonomy 中相似标签同组。
- Rate 优先 Moka 沟通 Note，无费率 Note 才用 Profile 的 USD/小时字段；严格按实际值与五档开闭区间匹配。截图截断或未读取全部标签时，不将可见前缀伪称为完整既有标签。
- 输出每组的建议标签、来源、理由、直接事实或推断、已有/未知、待核实事项。单列岗位项目标记与能力标签；区分初步 Tier 与已完成评估。未核实现行库或未读完整旧值时，不声称标签 Active、已存在、需要新增或已写入。
